# Contributing

Thanks for wanting to contribute!

## Adding a new API/tool

1. Fork this repo
2. Add your entry in alphabetical order within its section
3. Include: name, link, free tier info, pricing, and a brief note
4. Submit a PR

## Guidelines

- Only include APIs/tools that are currently active and maintained
- Free tier or open source preferred
- No affiliate links
- Keep descriptions concise (under 100 characters)
